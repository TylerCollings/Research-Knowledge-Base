# About: marginaleffects: Model to Meaning

**Type:** Website and R package

**Link:** [Official resource](https://marginaleffects.com/)

Resources for interpreting model estimates.

## Key details

- The R and Python package computes predictions, comparisons, slopes, and related model quantities.

## How to Use

1. Install the package for the language and environment used by your fitted model, following the Quick Start installation instructions. ([source](https://marginaleffects.com/bonus/get_started.html))
2. Start from a fitted model and select the target quantity: `predictions()`, `comparisons()`, or `slopes()`; use the Quick Start to specify the estimand and uncertainty output. ([source](https://marginaleffects.com/bonus/get_started.html))
