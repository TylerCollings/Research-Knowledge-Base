# About: Mixtape-Sessions

**Type:** GitHub courses

**Link:** [Official resource](https://github.com/Mixtape-Sessions/)

Courses in causal inference.

## Key details

- The GitHub organization hosts causal-inference workshops, including multi-session courses and shorter topic-focused tracks.

## How to Use

1. Browse the organization repositories and select a Mixtape Session or Track that matches the method or topic you need. ([source](https://github.com/Mixtape-Sessions))
2. Open that course repository and follow its posted readings, slides, and coding-lab materials in order. ([source](https://github.com/Mixtape-Sessions))
