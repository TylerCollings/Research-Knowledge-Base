# About: DAGGLE

**Type:** Shiny app

**Link:** [Official resource](https://cbdrh.shinyapps.io/daggle)

A tutorial and activity for directed acyclic graphs.

## Key details

- The app has Tutorial and Random modes for practicing graphical rules for minimally sufficient adjustment sets.

## How to Use

1. Open the app and choose Tutorial mode for the guided introduction or Random mode for a generated DAG exercise. ([source](https://doi.org/10.1093/ije/dyad038))
2. Apply the graphical rules to select a minimally sufficient adjustment set, then use Reveal Solution to compare your answer with the app's valid sets. ([source](https://doi.org/10.1093/ije/dyad038))
