# About: DAGitty

**Type:** Website

**Link:** [Official resource](https://www.dagitty.net/)

A website for drawing and analysing causal diagrams.

## Key details

- DAGitty draws and analyzes DAGs, including adjustment sets, instrumental variables, and testable implications.

## How to Use

1. Open DAGitty and create a diagram by adding variables and arrows that represent the assumed causal structure; set the exposure and outcome for the analysis. ([source](https://www.dagitty.net/manual-3.x.pdf))
2. Use the effect-analysis and adjustment-set views to inspect identification, then save or export the diagram as documented in the manual. ([source](https://www.dagitty.net/manual-3.x.pdf))
