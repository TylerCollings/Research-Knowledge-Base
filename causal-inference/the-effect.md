# About: The Effect: An Introduction to Research Design and Causality

**Type:** Online book

**Link:** [Official resource](https://www.theeffectbook.net/index.html)

An online introduction to research design and causality.

## Key details

- The book covers causal research design, identification, causal diagrams, and common research designs.

## How to Use

1. Use the chapter navigation to read the research-design and causal-diagram material before selecting a method; the author points readers to Chapters 1, 2, and 5 through 8 for project design. ([source](https://theeffectbook.net/))
2. For a specific design, use the matching Toolbox chapter and its implementation examples. Install the `causaldata` package only if you want to run the book's example code. ([source](https://theeffectbook.net/))
