# About: quartets

**Type:** GitHub datasets

**Link:** [Official resource](https://r-causal.github.io/quartets/)

Datasets to help teach statistics.

## Key details

- The R package supplies teaching datasets that show why visualizations and data-generating context matter alongside summary statistics.

## How to Use

1. Install and attach the package with `install.packages('quartets')` and `library(quartets)`. ([source](https://r-causal.github.io/quartets/))
2. Use a documented dataset such as `anscombe_quartet` or `causal_quartet`; plot by dataset as shown in the package examples before comparing summary statistics or causal estimates. ([source](https://r-causal.github.io/quartets/))
