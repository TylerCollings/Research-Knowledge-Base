# Biomechanics Knowledge Base

A curated, searchable reference for biomechanics research resources and practical methods. Pages are written for the research group and for agents helping with preprocessing, analysis, and interpretation.

## Browse

- [Methods](methods/README.md)
- [Resources](resources/README.md)
- [Workflows](workflows/README.md)

Each tool, package, dataset, or repository has its own page. Pages briefly explain what the resource does, give the specific information needed to use or assess it, and link to further details.
