# About: R for Data Science (2nd Edition)

**Type:** Online book

**Link:** [Official resource](https://r4ds.hadley.nz/)

Online book on data science with R.

## Key details

- The book teaches a reproducible R workflow covering import, tidying, understanding, and communication.

## How to Use

1. Use the online contents to follow the workflow chapters in order, beginning with data import and tidying for a new analysis. ([source](https://r4ds.hadley.nz/intro.html))
2. To run examples, install R and RStudio, install the tidyverse with `install.packages('tidyverse')`, and load it with `library(tidyverse)` as described in the book. ([source](https://r4ds.hadley.nz/intro.html))
