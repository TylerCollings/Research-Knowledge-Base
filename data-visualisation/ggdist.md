# About: ggdist: Slab + interval stats and geoms

**Type:** R package

**Link:** [Official resource](https://cran.r-project.org/web/packages/ggdist/vignettes/slabinterval.html)

R package documentation for slab and interval statistics and geoms.

## Key details

- The package provides ggplot2 geoms and stats for visualizing distributions and uncertainty, including slab-interval and lineribbon families.

## How to Use

1. Install and attach the package with `install.packages('ggdist')` and `library(ggdist)`. ([source](https://cran.r-project.org/web/packages/ggdist/refman/ggdist.html))
2. Choose a documented geom family for the data and uncertainty display, then follow the matching vignette, such as `vignette('slabinterval', package = 'ggdist')`, to build the plot layer. ([source](https://cran.r-project.org/web/packages/ggdist/refman/ggdist.html))
