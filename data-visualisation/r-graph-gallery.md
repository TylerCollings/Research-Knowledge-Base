# About: The R Graph Gallery

**Type:** Website

**Link:** [Official resource](https://r-graph-gallery.com/index.html)

Examples of data visualisation in R.

## Key details

- The gallery groups chart examples by chart type and provides reproducible R code with explanations.

## How to Use

1. Browse chart families and select an example that matches the data structure and comparison you need to show. ([source](https://r-graph-gallery.com/all-graphs))
2. Read the explanation, adapt the reproducible R code to your variables, and consult any package documentation linked by the example. ([source](https://r-graph-gallery.com/all-graphs))
