# About: ggplot2 extensions

**Type:** Package list

**Link:** [Official resource](https://exts.ggplot2.tidyverse.org/gallery/)

Gallery of extensions to ggplot2.

## Key details

- The gallery indexes packages that extend ggplot2.

## How to Use

1. Browse the gallery for an extension that supplies the chart or feature needed. ([source](https://exts.ggplot2.tidyverse.org/gallery/))
2. Open the extension's own documentation for installation and usage, then use its documented example with your ggplot object. ([source](https://exts.ggplot2.tidyverse.org/gallery/))
