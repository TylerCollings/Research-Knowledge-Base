# About: pytransform3d

**Type:** Python library

**Link:** [Official resource](https://dfki-ric.github.io/pytransform3d/)

Python library documentation covering 3D transformations and definitions.

## Key details

- Supports common 3D rotation and translation representations, conversions, and transformation chains.

## How to Use

1. Install with `python -m pip install pytransform3d`; add the documented `[all]` extra only when you need its optional visualization or mesh features. ([source](https://dfki-ric.github.io/pytransform3d/install.html))
2. Use the API documentation to choose the relevant rotation, translation, or transform-manager function, and check its stated conventions before combining transforms. ([source](https://dfki-ric.github.io/pytransform3d/install.html))
