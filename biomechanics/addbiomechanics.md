# About: AddBiomechanics

**Type:** Dataset and processing platform

**Link:** [Official resource](https://addbiomechanics.org/)

Open access dataset and processing platform.

## Key details

- The service processes motion-capture files into scaled OpenSim models and inverse-kinematics and inverse-dynamics results. Uploaded data are automatically shared under CC BY 4.0.

## How to Use

1. Before upload, confirm the data can be shared under CC BY 4.0. Check that the model marker set matches the experimental marker files and review the service's input tips. ([source](https://www.addbiomechanics.org/instructions.html))
2. Open Process Your Data, submit the prepared motion-capture files, then review per-trial warnings and returned outputs. ([source](https://www.addbiomechanics.org/instructions.html))
