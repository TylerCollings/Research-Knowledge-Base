# About: EZC3D

**Type:** Python library

**Link:** [Official resource](https://github.com/pyomeca/ezc3d)

A Python library to read, modify, and write C3D files.

## Key details

- The Python binding reads, modifies, and writes C3D files.

## How to Use

1. Install the Python binding in the environment that will run the analysis with `python -m pip install ezc3d`. ([source](https://github.com/pyomeca/ezc3d))
2. Read a C3D with `from ezc3d import c3d` and `c = c3d('path/to/file.c3d')`; inspect the documented `parameters` and `data` sections before transforming or writing the file. ([source](https://github.com/pyomeca/ezc3d))
