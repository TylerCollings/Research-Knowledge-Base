# Instructions for agents

- Start with this README and follow its links to the relevant page.
- Organize content in clear topic area folders at the top level. Give each topic folder a `README.md` that indexes and links to its individual pages, so agents can search the index to find the appropriate tool, page, or information.
- When adding or moving a page, update the `README.md` index in its topic folder and the top-level README when the topic area changes.
- Use the page's cited sources and linked documentation for details that are not recorded here.
- Keep resource pages concise and specific to biomechanics research use.
- Do not infer or invent setup steps, capabilities, validation, or limitations. Mark unknown details as unknown or link to authoritative documentation.
- Keep each tool, package, dataset, or repository on its own page.
- Separate evidence-backed method guidance from group-specific conventions.
- Update a page when its source or recommended use changes.
- Add a separate page for each tool, package, dataset, repository, or method.
- Use the [template](templates/template.md) for resource pages. Make its **How to Use** steps specific to the resource itself, and support operational instructions with authoritative sources.
- Keep entries concise: explain what the item does, record only information needed to use or assess it, and link to authoritative details.
- Before completing a change, check that links work, claims are supported by cited sources, and group conventions are clearly distinguished from general method guidance.
