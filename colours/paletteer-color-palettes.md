# About: Paletteer color palettes

**Type:** Website

**Link:** [Official resource](https://r-charts.com/color-palettes/)

A collection of Paletteer color palettes.

## Key details

- The linked page introduces paletteer, which makes palettes from multiple R packages available through a common interface.

## How to Use

1. Install the package with `install.packages('paletteer')` and attach it with `library(paletteer)`. ([source](https://cran.r-project.org/web/packages/paletteer/refman/paletteer.html))
2. In ggplot2, choose a documented palette name in `package::palette` form and add the appropriate `scale_colour_paletteer_d()` or `scale_fill_paletteer_d()` layer. ([source](https://cran.r-project.org/web/packages/paletteer/refman/paletteer.html))
