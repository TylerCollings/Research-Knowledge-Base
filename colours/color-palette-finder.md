# About: Color palette finder

**Type:** Website

**Link:** [Official resource](https://r-graph-gallery.com/color-palette-finder)

A color palette finder from the R Graph Gallery.

## Key details

- The interactive finder previews palettes on charts, filters palettes, and provides reproducible code and hexadecimal values.

## How to Use

1. Use the palette selector and filters to compare palette types and lengths on the example charts. ([source](https://r-graph-gallery.com/color-palette-finder))
2. Hover over a chart for the code snippet, or export the palette's hexadecimal values; use the displayed `paletteer` code when building an R chart. ([source](https://r-graph-gallery.com/color-palette-finder))
