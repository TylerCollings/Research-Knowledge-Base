# About: Palette generator

**Type:** Website

**Link:** [Official resource](https://www.learnui.design/tools/data-color-picker.html)

A tool for generating color palettes.

## Key details

- The tool creates data-visualization palettes and offers palette, single-hue, and divergent modes.

## How to Use

1. Choose Palette, Single Hue, or Divergent mode, then set the number of colors and any documented background or endpoint options. ([source](https://www.learnui.design/tools/data-color-picker.html))
2. Use Copy HEX Values or Export as SVG to bring the generated palette into the target visualization, and inspect its contrast in context. ([source](https://www.learnui.design/tools/data-color-picker.html))
