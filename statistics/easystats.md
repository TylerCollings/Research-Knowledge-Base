# About: easystats

**Type:** R framework

**Link:** [Official resource](https://easystats.github.io/easystats/)

An R framework for statistical modeling, visualization, and reporting.

## Key details

- The framework groups R packages for statistical modeling, visualization, and reporting.

## How to Use

1. Install the CRAN release with `install.packages('easystats')`; run `easystats::install_suggested()` if you need the optional packages used by additional functions. ([source](https://easystats.github.io/easystats/))
2. Load the package or the specific easystats package needed for the task, then follow its function reference and examples. ([source](https://easystats.github.io/easystats/))
