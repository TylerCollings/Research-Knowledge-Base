# About: rstatix

**Type:** R package

**Link:** [Official resource](https://rpkgs.datanovia.com/rstatix/)

A pipe-friendly R package for performing basic statistical tests.

## Key details

- Functions use a pipe-friendly interface for common tests, including `t_test()` and `pairwise_t_test()`.

## How to Use

1. Install and attach the package with `install.packages('rstatix')` and `library(rstatix)`. ([source](https://rpkgs.datanovia.com/rstatix/articles/rstatix.html))
2. Choose the test matching the question and pass the data with the documented formula, such as `outcome ~ group` to `t_test()`; check the function reference for pairing, adjustment, and other arguments. ([source](https://rpkgs.datanovia.com/rstatix/articles/rstatix.html))
