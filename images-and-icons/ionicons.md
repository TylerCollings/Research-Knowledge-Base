# About: ionicons

**Type:** Icon library

**Link:** [Official resource](https://ionic.io/ionicons/)

Free icons.

## Key details

- Ionicons is an open-source icon library. In Ionic Framework it is included by default; a standalone web page can use the Ionicons Web Component.

## How to Use

1. Browse the icon catalog. For Ionic Framework, use the installed component; otherwise follow the web component installation instructions in the usage guide. ([Ionicons usage guide](https://ionic.io/ionicons/usage))
2. Add the selected icon with an `ion-icon` element and its documented `name`; add `aria-hidden="true"` for decorative icons or an `aria-label` when the icon itself conveys information. ([Ionicons usage guide](https://ionic.io/ionicons/usage))
