# About: Flaticon

**Type:** Icons and stickers

## Key details

- Free use requires attribution under Flaticon's free license; the terms describe how to place the credit for web and non-web uses. ([Flaticon license](https://media.flaticon.com/license/license.pdf))

## How to Use

1. Search for an icon or sticker that fits the intended use and open its individual asset page. ([Flaticon](https://www.flaticon.com/))
2. Check the selected asset's license. For the free license, include the author attribution in the final project as described by Flaticon. ([Flaticon license](https://media.flaticon.com/license/license.pdf))
